**Changed**

- With the line as the closed look, or a window rule that turns the notch into the line, a notice that pops up now opens the line into the notch for its few seconds, like a finished timer, and the line comes back after. Do Not Disturb, quiet hours, presentation mode and full-screen apps still send it to the history only ([#31](https://github.com/andrealo20/crest/issues/31)).

**Fixes**

- The Claude card in AI usage stays current on Windows without renewing the sign-in in a terminal. Claude Code renews its sign-in only while you use it; once that has expired, Crest reads the one the Claude desktop app keeps and renews by itself while it is open. Crest never renews or changes either sign-in ([#32](https://github.com/andrealo20/crest/pull/32)).
- A question from `crest-notify ask` that is too long to show whole is now refused instead of cut, so Allow can no longer approve a command whose end the notch did not show. The hook then leaves the decision to the agent's own prompt ([#33](https://github.com/andrealo20/crest/pull/33)).
- A calendar feed can no longer stop Crest or fill its memory: entries nested too deep are skipped, titles are capped and a repeating event keeps at most 500 dates ([#33](https://github.com/andrealo20/crest/pull/33)).
