Plugins, eleven languages, a calendar and a first-run setup.

- Plugins: a folder of HTML, CSS and JavaScript with a `crest-plugin.json` becomes a tool in the notch. Install it from Settings → Plugins; it runs sandboxed, with only the network addresses and storage it declares. Scripts can also put their own parts in the closed row with `crest-notify part`. How to write one: [docs/plugins.md](https://github.com/andrealo20/crest/blob/main/docs/plugins.md).
- Languages: English, Simplified Chinese, Spanish, Hindi, Arabic (right to left), French, Portuguese, Russian, Japanese, German and Italian. Crest follows the Windows language unless you pick one in Settings → General.
- Calendar: a read-only agenda from ICS links (Google, Outlook, iCloud) or CalDAV accounts, a notice before each event and the next event in the closed row.
- First run: a short setup picks a preset (Music, Productivity, AI or your own tools), the closed look and edge, and shows the shortcut. Settings → General runs it again.
- Volume and brightness: changes show in the closed notch, and Crest can hide the Windows indicator while it runs. Turning the option off brings the Windows indicator back.
- Lyrics: word by word where the source times words, with translation and romanisation for Japanese, Chinese and Korean, and more sources to look in.
- Monitors: the notch stays on the monitor you pick, follows the pointer, or shows a closed notch on every monitor.
- Toolbar: larger buttons, brighter icons and a mark under the tool you are on.
- Downloads: ARM64 installers and portable zips, and a `SHA256SUMS` file to check them. Settings → General → Copy diagnostics copies what an issue report needs.
- Fixes: quick drop with the Shelf off, amounts written as "1,000" or "1.234,5", a second scrollbar in the terminal, Ask translating into German, stale header buttons after fast switching between tools.
